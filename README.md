# HORIZON character model assets

Lossless delivery data for individually exported and park-browser-tested HORIZON characters. This initial collection contains 13 complete character exports, not a completed collection of 500. Each retains its original body, proportions, clothing, hair, skeleton and animation. No character rescaling or substitute identities.

`manifest.json` pins every delivery file and original GLB by SHA-256. Geometry buffers are gzip containers; decoded bytes and image bytes are unchanged. Relative GLTF buffer/texture references remain valid. Models use metre units and their original scale.

This repository contains model files and notices only. It contains no game implementation, student identities, accounts, session secrets or database connections. It is not a separate park viewer.

## Licences

MakeHuman-derived body, clothing and hair assets are CC0 1.0; motion has separate CMU usage terms, including the restriction against direct resale of the motion data. This collection is provided free, with the original source and acknowledgement notices in `LICENSES/`. It is incorrect to describe the entire motion collection as solely CC0.

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.
